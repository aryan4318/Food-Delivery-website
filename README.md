# FoodieGo — Food Delivery Website

A frontend-only food delivery web application built with HTML, CSS and vanilla JavaScript.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Included
### Customer
- Registration and login
- Customer / Restaurant / Admin roles
- Demo Google login
- Demo forgot-password flow
- Restaurant/dish/cuisine search
- Price, rating, vegetarian and delivery-time filters
- Sort by rating, popularity, price and distance
- Restaurant details and food categories
- Veg/non-veg indicators
- Food customization and add-ons
- Multiple quantities
- Special instructions
- Automatic cart totals and delivery fee
- Checkout
- Order history
- 5-step order tracking
- Simulated status progression

### Restaurant
- Restaurant dashboard
- Today's orders / revenue / rating / best seller
- Add food
- Edit food
- Delete food
- Menu management
- Order management
- Accept/progress orders
- Inventory alerts
- Sales/performance section
- Reviews placeholder

### Admin
- Total users
- Restaurants
- Orders
- Revenue
- Cancelled orders
- Most popular food
- Most active restaurant
- Daily/weekly/monthly sales
- User management
- Restaurant management

## Important
This is a portfolio/college-project frontend demo. Authentication, Google OAuth, payments, email reset, real-time tracking and database persistence are simulated with `localStorage`. For production, connect a backend/API and real authentication provider.
